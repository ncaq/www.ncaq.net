# ライセンス

サイトをビルドするためのコード([src/](src/)など)は、
[Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0)ライセンスです。

その他の[site/以下](site/)などの細かいライセンスは特記されていなければ定めていません。

記事に含まれる第三者の著作物には、
引用なのか転載なのか自分でも判別できない箇所があり、
全ての記事に統一したライセンスを定めるのが難しいためです。

当然のことですが引用は自由に行うことが出来ます。

引用を超えるコピーを行う場合ご連絡をいただければ、
重要ではない部分は雑なCCライセンスなどを個別に対応しようと思います。

## AI利用などに関する意思表示

ライセンスは定めていませんが、
閲覧、ダウンロード、検索インデックス、AIへの入力、AIの学習などに使うことは自由です。
利用は利用者の自己責任で行ってください。

この意思表示は以下の方法で機械可読にしています。

- [site/robots.txt](site/robots.txt)の`Content-Signal`と`Content-Usage`
- [site/\_headers](site/_headers)によるHTTPヘッダの`Content-Usage`と`tdm-reservation`
